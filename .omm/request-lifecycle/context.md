Three early exits shape the flow: (1) a fresh cached analysis for the same domain/user short-circuits before any collector runs; (2) exceeding `MAX_CONCURRENT_ANALYSES` raises `LimiteConcurrenceAtteinteError` → HTTP 429; (3) any exception during collection/scoring marks the analysis FAILED and commits, so it stays visible in history instead of vanishing on rollback. The create route accepts both JSON (no file) and multipart (with a warm-up CSV).
