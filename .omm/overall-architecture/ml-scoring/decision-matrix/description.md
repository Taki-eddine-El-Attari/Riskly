`DecisionMatrix` (`decision_matrix.py`): the business rulebook. Computes an authority score (weighted rank/backlinks/age), blends it with email-health, applies a hard security veto when malicious_prob ≥ 0.50 (→ DANGEROUS), and otherwise thresholds the final score into WORTH_BUYING / RISKY / NOT_WORTH_IT. Returns INSUFFICIENT_DATA when no external signal is available (dead/expired domain) rather than inventing a score.
