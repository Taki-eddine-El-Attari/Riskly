`feature_builder.py`: builds the exact feature rows both models expect. `build_risk_features` one-hot encodes TLD/country against fixed known-value lists and fills missing-flags, matching `model_risk.joblib`'s `feature_names_in_`. `build_profitability_features` extracts the last warm-up day and pins weekday/month to fixed training categories — preventing train/inference skew on categorical codes.
