Central orchestrator (`backend/app/services/analysis_service.py`). `analyze_domain()` is the single entry point every analysis flows through. It: normalizes the domain, checks the DB-backed freshness cache, enforces a per-user concurrency limit, fans out to all collectors concurrently (`_collect_all` via `asyncio.gather`), builds the feature dict, calls `quick_score()`, maps the engine verdict to the 3 stored verdicts, and writes the Analysis row plus per-source ApiLog entries. On any failure it marks the analysis FAILED and commits so it stays visible in history.
